# KoolSupport v0.6.4 — Generic demo identity

Replaced the old demonstration supportee name with **Wildheart** across browser defaults and the demo party roster. The addon itself generates named focus macros from the player-selected character and never hardcodes example names.

# KoolSupport v0.6.3 — release notes

- Increased button padding and line spacing, with pagination to avoid nested scrollbars.
- Macro Suite displays a primary cast label to the right of each row.
- Hover the '?' in the Lua addon for Blizzard's native spell tooltip when available, plus macro text.
- Offline preview shows a plain reference hint rather than inventing spell statistics.
- Preset and Custom selections remain independent but generate into the same suite.

## CurseForge packaging
Use KoolSupport_CurseForge_v0.6.3.zip for CurseForge upload (addon only).
The separate preview package is for development; the HTML representation is NOT actual in-game UI.

## Known limitations
Forever in-game validation is pending. For complex macros, a row indicates only the first /cast.
